# MERN Stack Internship - Task 1
## EduTech Solutions

## Objective
MERN Stack development environment setup.

## Tools Used
- Node.js
- Vite (React Frontend)
- Express.js (Backend)
- MongoDB (Local)

## How to Run

### Frontend:
cd frontend
npm install
npm run dev

### Backend:
cd server
node server.js
